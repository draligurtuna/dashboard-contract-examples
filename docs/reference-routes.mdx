Choose a source because it answers your current question. This directory groups 100 public references from the maintainer's three projects into different reading routes. It is an optional companion to the [reading workflow](/reading-workflow), not a runtime dependency or a collection of verified claims.

## How to use this directory

1. Write one question before opening a page.
2. Select the appropriate subject below and choose one source.
3. Preserve the source URL, the observed detail and a separate interpretation in your note.
4. Record a next check rather than treating a saved link as a completed review.

The source titles are retained in their original language so you can recognize the destination. A link to an author page is different from a link to an individual poem; a product page is different from a testing result. Keep those distinctions when labeling your own collection.

## Ownership and scope

Ali Gürtuna maintains AGProLabs, AliGurtuna.com and Babamın Şiir Defteri. These references disclose that ownership. They are not independent recommendations, a guarantee of outcomes or a request to purchase. The engineering examples are independent synthetic JavaScript exercises, with no private Pine source and no medical formulas copied from the linked sites.

Health material is educational, analytical tools do not guarantee trading results, and a literary interpretation may remain open. Read each destination's own scope and limitations. The directory is a selection, not a claim to list every URL on these websites.

## Return to the question

After reading, return to your note and identify one thing the source did not establish. This small step keeps a numerical result, a displayed analytical state or an interpretation from turning into a stronger claim than the evidence supports. Continue with the [contract reference](/contracts) if you are implementing the review interface yourself.
