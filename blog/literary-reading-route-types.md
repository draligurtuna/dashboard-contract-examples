---
title: Separate archives, interpretations and reading tools
date: 2026-10-27
description: Build a literary reading route that keeps source types and your own notes distinct.
---

A literary website can contain an author's archive, a work review, a guide to poetic form and an article about reading devices. All can help the same reader, but they answer different questions. A useful reading interface keeps those differences visible from the first link to the final note.

I maintain [Babamın Şiir Defteri](https://www.babaminsiirdefteri.com/), a family-rooted Turkish poetry and literature project. The routes below come from that project and are disclosed as my own references. This note was prepared with AI assistance. It reproduces no poem or book passage.

## Start with the kind of visit you intend

Before selecting a destination, complete one sentence: “For this visit, I want to…”. A reading log can then preserve the route type beside the original title:

| Purpose | Route type | A useful note to keep |
| --- | --- | --- |
| Find a writer or a work | Author and work index | The selected name and destination title |
| Explore an interpretation | Work-review archive | The claim you want to examine |
| Understand a formal term | Poetry-form guide | The term and the explanation you consulted |
| Check reading-device requirements | Practical reading guide | The file or layout requirement being tested |

The table describes navigation categories. It does not rank the literary value of a work or tell a reader which interpretation to adopt.

## An archive supplies a route into the material

The [poets-and-poems index](https://www.babaminsiirdefteri.com/sairler-ve-siirler/) lets a reader start with a writer, title or archive entry. Keep the chosen author's name with each reading note. A familiar title can appear in several contexts, so the title alone may be an incomplete reference.

An archive can also bring together material around a named historical figure. The [Mustafa Kemal Atatürk archive](https://www.babaminsiirdefteri.com/sair/mustafa-kemal-ataturk/) is one such navigation route. Inspect the title and type of the individual item you open; a collection heading does not make every entry the same kind of source.

For a software interface, the practical requirement is stable identity. If an archive is reordered, a saved route should continue to identify the original destination. A displayed row number is a position in a list, rather than a durable citation.

## Keep a work separate from an interpretation of it

The [work-review archive](https://www.babaminsiirdefteri.com/sair/eser-incelemeleri/) provides routes to explanatory and interpretive writing. In your own notes, distinguish the named work, the review's observations and your response to them. Save the original URL with the title so you can return to the context later.

A small worksheet can make that separation explicit:

```text
Work or topic:
Source title and original URL:
Source type: archive / work review / form guide / practical guide
Question before reading:
Observation after reading:
My interpretation:
Still unresolved:
```

Leaving the last field open is useful. Opening a link or finishing a page is not a reliable measure of comprehension.

## Use a form guide to clarify the question

The [poetry-types and forms collection](https://www.babaminsiirdefteri.com/sair/siir-turleri/) is a route for exploring terminology and formal features. Write down which term you are investigating before moving between examples. That keeps a reading session focused and makes later notes easier to compare.

The interface can help by retaining the source label as the reader moves between a form guide and an author archive. It should leave room for the reader's own interpretation instead of treating a category selection as a finished analysis.

## Reading hardware is another kind of research

The [e-book reader selection guide](https://www.babaminsiirdefteri.com/e-kitap-okuyucu-secimi/) supports a practical question about reading files and layouts. A device requirement belongs in a different field from an interpretation of a poem. Record the format, text layout and note-taking behavior you want to test with your own files.

This distinction avoids mixing “the file opens” with “the text is comfortable to read”. Long lines, Turkish characters and notes can be separate review points. This note makes no device recommendation or claim of hands-on testing.

## A bounded reading session

Choose one question, one route type and one original destination. Keep the source title with your notes. Record what you actually read, rather than marking an entire archive complete after one visit. Return through the index when you need another source type.

The repository's independent reading-route examples demonstrate software state and identity concepts only. They do not certify archive completeness, literary authority, copyright status or a reader's understanding.
